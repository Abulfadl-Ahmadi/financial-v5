# 👔 سامانه جامع مدیریت کارگاه تولیدی پوشاک (Financial ERP v5)

سامانه اتوماسیون و مدیریت کارگاه تولید پوشاک، انبار پارچه، برشگاه، خیاطی و حسابداری چند‌حسابی با پشتیبانی از **۷۵ پرسنل** و نقش‌های دسترسی سطح‌بندی‌شده.

---

## 🌟 ویژگی‌های کلیدی سیستم

### 1. 👥 مدیریت دسترسی و نقش‌ها (RBAC)
* **مدیر ارشد (OWNER)**: دسترسی به کل پیشخوان، سود ناخالص کارگاه، آمار مالی و ۷۵ پرسنل.
* **حسابدار ارشد (ACCOUNTANT)**: مدیریت حساب‌های بانکی، ثبت فیش‌های واریزی و تسویه‌حساب خیاط‌ها.
* **سرپرست کارگاه برش (CUTTING_SUPERVISOR)**: ثبت لایه‌بندی، محاسبه متراژ طاقه، تیراژ پوشاک و حاشیه سود برش.
* **سرپرست کارگاه خیاطی (SEWING_SUPERVISOR)**: تحویل پارت به خیاط‌ها، ثبت ضایعات و محاسبه کارمزد تکه‌ای.
* **مدیر انبار پارچه (WAREHOUSE_MANAGER)**: ورود طاقه‌های جدید، کدهای شید رنگ و پیگیری متراژ باقی‌مانده.
* **خیاط / کارگر (WORKER)**: مشاهده پیشرفت دوخت و کارمزدهای قابل دریافت.

### 2. 📦 انبار پارچه (`apps/inventory`)
* ثبت انواع پارچه و طاقه‌ها با کد طاقه، رنگ، کد شید (`Shade Code`) و تامین‌کننده.
* تغییر خودکار وضعیت طاقه (`موجود در انبار`, `در حال استفاده`, `تمام شده`).

### 3. ✂️ کارگاه برش (`apps/cutting`)
* لایه‌بندی دقیق پارچه‌ها و محاسبه فرمولی تعداد کل پوشاک.
* محاسبه خودکار **سود حاشیه برش**، **سود خیاطی** و **سود کل**.

### 4. 🪡 کارگاه خیاطی (`apps/sewing`)
* پیگیری درصد پیشرفت خیاط‌ها و کنترل کیفیت (تعداد ضایعات).
* تسویه‌حساب تکه‌ای و محاسبه کارمزد قابل پرداخت.

### 5. 💼 حسابداری و فیش‌ها (`apps/financial`)
* **شناسایی خودکار کارت‌های بانکی از روی BIN شش‌رقمی** (ملی، ملت، صادرات، تجارت، سپه و...).
* ثبت و پیگیری فیش‌های واریزی با کدهای پیگیری و تاریخ‌های شمسی.

## 🏗 معماری فنی (Tech Stack)

### **بک‌اند (Backend)**
* **فریم‌ورک**: Django 5 + Django Ninja API (FastAPI-like performance & Pydantic v2 validation)
* **مدیریت پکیج‌ها**: `uv` (Fast Python Package Installer)
* **احراز هویت**: JWT Tokens (`django-ninja-jwt`)
* **دیتابیس**: SQLite (قابل سوئیچ به PostgreSQL)
* **مستندات آنلاین API**: OpenAPI Swagger در `/api/docs`

### **فرانت‌اند (Frontend)**
* **فریم‌ورک**: React 18 + Vite + TypeScript
* **معماری دیزاین**: `shadcn/ui` + `shadcn-admin` Architecture
* **استایل‌دهی**: Tailwind CSS v3 + CSS Variables (`oklch`) + راست‌چین کامل (RTL)
* **فونت‌ها**: Vazirmatn (متون فارسی) + SF Mono / Inter (اعداد و مقادیر مالی)
* **تست**: Vitest

## 🚀 راهنمای نصب و اجرای پروژه

### **۱. اجرای بک‌اند (Django Backend)**

```bash
cd backend

# ۱. نصب وابستگی‌ها با uv
uv sync

# ۲. ساخت دیتابیس و مایگریشن‌ها
uv run python manage.py makemigrations users inventory cutting sewing financial
uv run python manage.py migrate

# ۳. ورود اطلاعات اولیه تست (Seeding)
uv run python seed_data.py

# ۴. اجرای سرور توسعه
uv run python manage.py runserver 8000
```
* **آدرس مستندات Swagger API**: 🔗 `http://127.0.0.1:8000/api/docs`
* **پنل مدیریت Django Admin**: 🔗 `http://127.0.0.1:8000/admin/` (نام کاربری: `admin` | رمز عبور: `admin123`)

---

### **۲. اجرای فرانت‌اند (React Vite Frontend)**

```bash
cd frontend

# ۱. نصب پکیج‌ها
npm install

# ۲. اجرای سرور فرانت‌اند
npm run dev
```
* **آدرس فرانت‌اند**: 🔗 `http://localhost:5173/`
